# ❓ Modo Ask: Entendendo o Código
Este prompt é usado para obter explicações técnicas sem realizar alterações nos arquivos.

**Contexto:** Use quando encontrar uma lógica complexa ou um erro de sintaxe.

**Exemplo de Prompt:**
> "Analise a função abaixo e explique, passo a passo, como ela lida com a concorrência de dados. Existe algum risco de memory leak nesta abordagem?"
